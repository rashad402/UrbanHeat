# Kochi boundary data

Generated by `scripts/prepare_boundaries.py` (re-run to refresh).

## Files
- `aoi_kochi.geojson` — Kochi Municipal Corporation boundary (single Polygon), used as the study AOI.
- `wards_kochi.geojson` — 77 ward polygons, properties: `ward_id`, `ward_no`, `ward_name`, `area_sqkm`.

## Known data-quality caveats
- The source is newline-delimited GeoJSON (one Feature per line); the prep script assembles it
  into standard FeatureCollections.
- **77 polygons total:** 71 have official `Ward_No` 1–71; **6 are real wards with missing
  attributes** (empty properties). These are kept and given synthetic ids `x<index>`
  (`ward_no = null`, `ward_name = null`). Kochi Corporation officially has 74 wards, so the
  labelling in this community dataset is imperfect — verify ward names against an official
  KMC source before using them in planner-facing output.
- CRS is WGS84 (EPSG:4326), lon/lat — matches Earth Engine input.
